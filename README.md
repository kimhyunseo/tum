Hachi Wardrobe - Flutter MVP skeleton

This folder contains the initial skeleton for the Hachi Wardrobe Flutter MVP.

Structure:
- lib/main.dart : minimal Flutter app entry
- pubspec.yaml : minimal pubspec
- lib/screens : placeholder for screens (home, wardrobe, recommendation)
- lib/models : data models
- lib/services : weather + storage service placeholders

Notes:
- Run `flutter pub get` then `flutter run` in this folder (requires Flutter SDK installed).
- This is a minimal starting point; implement features iteratively as planned.
